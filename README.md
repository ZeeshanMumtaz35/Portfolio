# Engineer Zeeshan Mumtaz - Portfolio

A complete static website with 17 projects, About and Skills, Education, Experience, original CV, and a comprehensive portfolio PDF. All images used on the website are included locally. No build, paid template, CDN, or installation is needed.

## Open locally
Open `index.html` in your browser. Navigation, galleries, thumbnail strips and project filters work without a server.

## Publish with GitHub Pages
1. Extract this ZIP on your computer.
2. Create or open your GitHub repository.
3. Upload the CONTENTS of this extracted folder to the repository root: `index.html`, the other HTML files, `assets`, `projects`, `downloads`, and `.nojekyll`. Do not upload only the ZIP, and do not place the website inside an extra parent folder.
4. In GitHub, open **Settings > Pages**.
5. Set **Source: Deploy from a branch**, choose **main** and **/(root)**, then Save.
6. Open the URL GitHub shows after deployment completes.

For a project repository the address usually contains the repository name. All site links are relative so they work in that configuration too. Keep the entire assets, projects and downloads folders together.

## Included downloads
- `downloads/Zeeshan-Mumtaz-CV.pdf`: original supplied CV.
- `downloads/Zeeshan-Mumtaz-Portfolio.pdf`: complete engineering portfolio, education and experience.

## Project galleries
Use the arrow buttons, thumbnail strip, or Left/Right arrow keys. Home/End select the first/last image. Expand opens a larger view; Escape closes it. No gallery autoplays.

Dragon AC Cooling Cart is project 15: three CAD views are first and the workshop fabrication photograph is last. The healthcare final year project is project 17, at the end of the project list.

## Editing
The design is in `assets/css/style.css` and behavior in `assets/js/main.js`. Text is in the HTML files. Replace images at the same relative paths to preserve links. Keep original project screenshots if maintaining a faithful record.

The website uses original code and user-supplied images, with visual inspiration from the provided portfolio reference. No third-party template source or assets are bundled.
